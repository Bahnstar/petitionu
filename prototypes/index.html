What we’re testing

  • Petition card: fixes nested <Link> bug, adds urgency color, velocity, milestones
  • Header: active state, search ⌘K, user menu, mobile behavior
  • Browsing: URL-synced filters, category colors, sticky controls
  • Detail: verified signatures, delivery timeline, classroom tie-in
  • Dashboard: removes fake “Impact 89” — uses real pipeline metrics
  • Classrooms: join-code ergonomics, member roles, empty states
